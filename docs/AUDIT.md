> **Инструкция для ИИ / разработчика (правила работы с проектом):**
> 1. **Среда разработки:** работа ведётся на Mac **через веб-интерфейс GitHub**, без локального запуска Flutter/Android Studio. Все сборки APK идут в облаке через GitHub Actions (`.github/workflows/build-apk.yml`, `ubuntu-24.04`, Flutter `stable` / `3.50.1`).

>    * Для **новых или небольших/средних файлов** выдавайте **полный готовый код файла** целиком.
>    * Для **точечных правок в больших файлах** (например, `lib/screens/map_screen.dart`) обязательно указывайте **точные номера строк и текстовый якорь для поиска (`Cmd + F`)**, а также блоки «Что удалить» и «Что вставить». *(Примечание: в копии `map_screen.dart` на GitHub из-за вставок через браузер могут присутствовать лишние пустые строки — фактические номера строк могут быть примерно в ~1.9 раза больше эталонных).*
> 3. **Проверка совместимости:** учитывайте Flutter `3.50.1`, AGP `9.1.1`, Gradle `9.3.1`, Kotlin `2.4.10`, `compileSdk 36`, `maplibre_gl: ^0.28.0`, `share_plus: ^13.3.1`.

## 1. 🎯 О проекте
**GeoHunt** — мобильное приложение (Android, кодовая база Flutter) для координации группы охотников в реальном времени при отсутствии голосовой связи и нестабильном интернете.

### Реализованные возможности
* **Стартовая инструкция (`OnboardingScreen`):**
  * 5 интерактивных экранов с описанием всех возможностей приложения (группы/роли, карта/слои/кэш/круги, события/SOS, треки/экспорт GPX и CSV, экономия батареи и разрешения Android).
  * Чекбокс **«Не показывать при каждом запуске»** (сохраняется в `setting_skip_onboarding`).
  * Возможность повторно открыть инструкцию или включить/выключить автопоказ в **Настройках** («Инструкция и обучение»).
* **Группы по коду:** создание группы с 4-значным кодом, безопасный поиск и вход по коду через RPC, выбор уникального имени в группе и роли (`Стрелок`, `Загонщик`, `Егерь`, `Нет`) с цветовой индикацией.
* **Карта в реальном времени (`MapLibre GL`):**
  * **3 режима карты:**
    * **Улицы:** OpenFreeMap Positron (`https://tiles.openfreemap.org/styles/positron`).
    * **Спутник:** Esri World Imagery / Maxar (детальные снимки, зум до `17`, тайлы `{z}/{y}/{x}`).
    * **Гибрид:** Esri World Imagery + векторные водотоки (`waterway`), дороги с тёмным контуром (`roads_casing` + `roads`) и контрастные подписи (`place`).
  * Переключение в **офлайн-режим кэша** (`setOffline`) + оранжевый бейдж на карте.
  * Вращающийся по компасу/GPS маркер пользователя (плавное обновление через `setGeoJsonSource`).
  * Геодезические **круги расстояния** вокруг маркера (по умолчанию `100 / 200 / 300 м`, настраиваются в UI) с подписями и настройкой отображения.
  * **Умный компас:** красно-белая стрелка появляется только при повороте карты (`> 0.5°`) и возвращает ориентацию на Север по нажатию.
* **Меню карты (`⋮` в `AppBar` `MapScreen`, актуальный порядок):**
  1. **История треков** (`Icons.history`)
  2. **Экспорт событий (GPX / CSV)** (`Icons.share_outlined`)
  3. **Круги (...)** (`Icons.radar` слева + чекбокс `Icons.check_box` / `Icons.check_box_outline_blank` справа)
  4. **Офлайн-режим (кэш)** (`Icons.cloud_off` слева + чекбокс `Icons.check_box` / `Icons.check_box_outline_blank` справа; расположен **выше** Настроек)
  5. **Настройки** (`Icons.settings`)
  6. Разделитель + **Выйти из группы** (`Icons.logout`, красный)
* **Координация группы:**
  * Живое отображение позиций напарников через Supabase Realtime + легенда группы с возрастом последней связи (метки старше 1 часа — серые).
  * События на охоте (**«Видел»**, **«Подранен»**, **«Добыт»**) с заметками, программной генерацией иконок (`Canvas`) и звуковыми оповещениями.
  * Экстренный сигнал **SOS** с зацикленной сиреной, тревожным окном и выделением точки красным.
* **Запись треков, история и экспорт:**
  * Непрерывная запись маршрута в локальный файл `active_track.jsonl` (работает при выключенном экране в фоновом сервисе независимо от интервала отправки координат в БД; кэш изолятов синхронизируется через `TrackRecorder.invalidateCache()`).
  * Фильтрация GPS-шума (`accuracy <= 35 м`, шаг `>= 8 м`), отображение линии трека на карте, сжатие алгоритмом **Дугласа–Пекера** (`epsilon = 5 м`) при сохранении.
  * Офлайн-очередь сохранения треков (`pending_tracks/`) с автоматической доотправкой при появлении интернета.
  * Экраны **«История треков»** и **«Просмотр трека»** (линия, старт/финиш, автозум, смена слоёв Улицы/Спутник/Гибрид).
  * **Экспорт в GPX 1.1 и CSV (`TrackExporter`):**
    * Экспорт любого трека из «Истории треков» и «Просмотра трека» (в GPX включаются точки трека `<trk>` и события охоты группы `<wpt>` за интервал трека при наличии сети и совпадении `groupId`; в CSV — UTF-8 с BOM для Excel).
    * Экспорт текущих событий группы напрямую из меню карты.
* **Настройки (`SettingsScreen`):**
  * Точность GPS (`high / balanced / low`).
  * Частота отправки координат в БД (`30с / 60с / 300с`).
  * Круги расстояния: тумблер + редактор радиусов (`InputChip`, добавление от `10` до `50 000 м`, быстрые пресеты `50..2000 м`, минимум 1 радиус, сброс к `100/200/300 м`).
  * Инструкция и обучение: тумблер автопоказа при запуске + кнопка «Открыть инструкцию».

## 2. 🛠 Технологический стек и зависимости
* **Язык и фреймворк:** Dart `>=3.0.0 <4.0.0`, Flutter `>=3.0.0` (CI использует `stable` / `3.50.1`).
* **Карты:** `maplibre_gl: ^0.28.0`.
* **Бэкенд:** Supabase (`supabase_flutter: ^2.8.0`) — PostgreSQL, Anonymous Auth, RLS, Realtime, `pg_cron`.
* **Геолокация и сенсоры:** `geolocator: ^14.0.0`, `flutter_compass: ^0.8.1`.
* **Фон и уведомления:** `flutter_background_service: ^5.0.10`, `flutter_local_notifications: ^17.2.3`.
* **Хранилище, медиа и экспорт:** `shared_preferences: ^2.3.0`, `path_provider: ^2.1.3`, `audioplayers: ^6.0.0`, `share_plus: ^13.3.1` (`SharePlus.instance.share(ShareParams(...))`).
* **CI/CD и Android:** GitHub Actions (`ubuntu-24.04`), Java 21 (Temurin), Gradle `9.3.1`, AGP `9.1.1`, Kotlin `2.4.10`, `compileSdk 36`, NDK `28.2.13676358`, `flutter_launcher_icons: ^0.14.1`.

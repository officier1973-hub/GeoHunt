Политика конфиденциальности приложения «Коллективная охота»

Пакет приложения: ru.geohunt.app · Дата обновления: 24.11.2026

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает мобильное приложение «Коллективная охота» (далее — «Приложение») и для каких целей они используются.

1. Какие данные обрабатываются

Приложение не требует регистрации по номеру телефона, электронной почте или паспортным данным. Используется анонимная техническая сессия.

  • Геолокация (включая работу в фоновом режиме): координаты устройства передаются участникам вашей текущей группы в реальном времени, используются для отображения вашей позиции на карте, передачи экстренного сигнала SOS и локальной/облачной записи ваших маршрутов (треков) даже при выключенном экране.
  • Имя и роль в группе: произвольное имя (никнейм) и выбранная роль («Стрелок», «Загонщик», «Егерь»), заданные пользователем добровольно для отображения на карте участникам группы.
  • События на охоте: тип события («Видел», «Подранен», «Добыт»), координаты и необязательная текстовая заметка, отправленные пользователем группе.
  • Маршруты (треки): записанные пользователем координаты и время пути.
  • Локальные настройки: параметры точности GPS, частоты обновления, кругов дистанции и кэш картографических тайлов, хранящиеся на устройстве.

2. Цели обработки данных

  • Координация участников одной группы по 4-значному коду на карте в реальном времени.
  • Оповещение группы о событиях охоты и экстренном сигнале SOS.
  • Запись, хранение, просмотр и экспорт (GPX / CSV) личных маршрутов пользователя.

3. Хранение, сторонние сервисы и автоудаление

  • Для синхронизации данных группы и хранения треков используется облачная база данных Supabase (передача данных защищена HTTPS/TLS и политиками разграничения доступа RLS).
  • Временные данные групп очищаются автоматически: координаты неактивных участников — через 2 часа, события — через 7 дней, пустые группы — через 7 дней.
  • Для отображения карт загружаются картографические тайлы сервисов OpenFreeMap (© OpenStreetMap contributors) и Esri World Imagery (Tiles © Esri — Maxar, Earthstar Geographics).
  • Приложение не продаёт данные пользователей и не передаёт их рекламным сетям или брокерам данных.

4. Удаление данных пользователем

Пользователь в любой момент может удалить свои данные:

  • выйти из группы на экране карты (метка участника удаляется с сервера);
  • удалить отдельные сохранённые треки в разделе «История треков»;
  • полностью удалить все свои облачные треки, метку в группе и локальные данные кнопкой «Удалить все мои данные» в разделе «Настройки» внутри Приложения.

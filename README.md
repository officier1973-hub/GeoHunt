# GeoHunt

Мобильное приложение на Flutter для координации группы охотников в реальном времени.

## Основные возможности

* **Группы по 4-значному коду:** быстрое создание группы или подключение к существующей.
* **Роли и карта в реальном времени:** отображение участников (`Стрелок`, `Загонщик`, `Егерь`) через Supabase Realtime с временем последней активности.
* **Три слоя карты:** Улицы (OpenFreeMap Positron), Спутник (EOxCloudless), Гибрид + режим офлайн-кэша.
* **Круги расстояния и компас:** геодезические кольца `100 / 200 / 300 м` вокруг вашего маркера и компас для возврата карты на Север.
* **События и SOS:** отметки «Видел», «Подранен», «Добыт» с заметками и звуками; кнопка SOS с громкой сиреной для всей группы.
* **Запись треков:** запись маршрута в фоне при выключенном экране, отрисовка пути на карте, сжатие точек (алгоритм Дугласа–Пекера), офлайн-очередь отправки и экран истории с просмотром маршрутов.
* **Экономия батареи:** настройка точности GPS и частоты отправки координат.

## Технологический стек

* **Frontend:** Flutter (`>=3.0.0`, Dart `>=3.0.0 <4.0.0`), `maplibre_gl`, `geolocator`, `flutter_compass`, `flutter_background_service`, `audioplayers`, `path_provider`
* **Backend:** Supabase (PostgreSQL, Anonymous Auth, RLS, Realtime, `pg_cron`)
* **CI/CD:** GitHub Actions (сборка Release APK на `ubuntu-24.04`)

## Структура репозитория

* `lib/main.dart` — инициализация Supabase, авторизация и фоновый сервис отслеживания.
* `lib/app_session.dart` — управление сессией группы и охотника.
* `lib/app_settings.dart` — настройки GPS, интервалов и кругов расстояния.
* `lib/track_recorder.dart` — локальный JSONL-буфер трека, фильтрация шума, Дуглас–Пекер, синхронизация с Supabase.
* `lib/screens/` — экраны входа, карты (`map_screen.dart`), настроек, истории и просмотра треков.
* `docs/AUDIT.md` — подробный технический аудит, схема БД, контракты слоёв/сервиса и дорожная карта.

## Настройка Supabase

Для развёртывания бэкенда выполните в Supabase SQL Editor:
1. Основной скрипт создания таблиц `groups`, `hunters`, `events`, функций `get_my_group_id()` / `get_group_by_code()`, триггеров, RLS-политик, публикации `supabase_realtime` и задач `pg_cron`.
2. Скрипт создания таблицы `tracks` и её RLS-политик.

Подробная схема и технические контракты описаны в [`docs/AUDIT.md`](docs/AUDIT.md).

## Сборка APK

Сборка выполняется автоматически через GitHub Actions (`.github/workflows/build-apk.yml`) при пуше в ветку `main` или вручную через `workflow_dispatch`. Готовый файл `GeoHunt-release.apk` загружается в артефакты (`GeoHunt-release-apk`).
